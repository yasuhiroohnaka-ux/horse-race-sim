## 着順別の特徴

- 1着馬は placeProb 中央値 61.8% / placeScore 0.502 / top3Stability 0.564。4着以下の 52.6% / 0.397 / 0.447 とは明確に差があり、まず「3着内側の土台」を持っている。
- ただし 1着馬と 2-3着馬の差は小さく、simWinProb は 1着 4.8% に対して 2-3着 7.2%、edge は 1着 -8.2pt に対して 2-3着 -3.2pt。現状指標は「上位か下位か」は分けるが、「勝ち切りか2-3着か」の切り分けはまだ弱い。
- scoreGap は 1着馬 0.117、2-3着馬 0.127、4着以下 0.241。上位馬ほど placeScore 首位との差が小さく、低 gap 側は3着内率も高い。

## 人気別の観察

- 上位人気好走馬 (61頭) は placeProb 中央値 67.8% / placeScore 0.575 / edge -12.2pt。
- 人気薄好走馬 (23頭) は valueScore 中央値 0.541 が高い一方で、placeProb 50.5% と top3Stability 0.384 も一定水準を持っており、valueScore だけで来ている形ではない。

## 候補の成功/失敗パターン

- 単複本命の好走群は placeProb 中央値 73.5% / placeScore 0.644 / selectionScoreGap 0.085 / simWinProb 14.1%。飛んだ群は 69.8% / 0.609 / 0.039 / 8.3% で、差は大きくないが「押し出し差」と sim 側の裏付けが弱いと崩れやすい。
- 相手候補の好走群は placeProb 67.7% / top3Stability 0.625。凡走群は 65.0% / 0.613 で、差は小さいが valueScore より placeProb と安定度のほうが残り方に寄っていそう。scoreGap は hit/miss で素直に分かれず、危険シグナルとしては弱め。
- ワイド高配当狙いの好走群は valueScore 0.691 / placeReturnEdge 0.933 / placeProb 60.3%。凡走群も 0.692 / 0.936 / 60.4% とかなり近く、現状の wide 判定は刺さるケースと刺さらないケースをまだ十分に分離できていない。

## valueScore 高いだけの馬との違い

- valueScore 上位四分位 (閾値 0.633) は 145頭いて、そのうち好走は 38頭 (26.207%)。
- 同じ高 valueScore 帯でも、好走馬は placeProb 中央値 60.1% / top3Stability 0.560、凡走馬は 59.2% / 0.551。valueScore に加えて「複勝側の土台」が必要そう。

## 四分位スプレッド上位

- placeRank: 良い四分位と悪い四分位の top3率差 44.9pt / win率差 13.8pt。
- placeProb: 良い四分位と悪い四分位の top3率差 43.5pt / win率差 15.2pt。
- placeScore: 良い四分位と悪い四分位の top3率差 42.0pt / win率差 13.0pt。
- top3Stability: 良い四分位と悪い四分位の top3率差 40.6pt / win率差 12.3pt。
- scoreGap: 良い四分位と悪い四分位の top3率差 34.8pt / win率差 12.3pt。
- edge は正方向 quartile のほうが top3率・win率ともに低く、結果シグナルというより『妙味/市場とのズレ』寄りの役割に見える。
- placeReturnEdge は四分位差がほぼ出ておらず、単独では3着内向きシグナルになっていない。

## 断定を急がない点

- 対象はワークスペース内で復元できた 2026-03-06 から 2026-04-05 の 39レースで、フェブラリーS当日を含む 2月後半データは確認できていない。
- ワイド高配当狙いの好走件数は少なめなので、valueScore や placeReturnEdge の差は方向感の確認に留めるべき。
- scoreGap は本レポートでは placeScore 首位との差として全頭共通化しており、選出時に表示される selectionScoreGap とは別物として見ている。

## 次の改修候補としての仮説

- 勝ち切り役は simWinProb / edge の役割が強く、3着内役は placeProb / top3Stability の役割が強い可能性がある。
- 相手候補とワイド高配当狙いは、valueScore 単独ではなく placeProb か top3Stability の最低ラインが必要かもしれない。
- 本命が飛ぶケースは、placeScore そのものより selectionScoreGap や simEdge の押し出し不足を先に確認したほうが良い可能性がある。
- ただし今回は観察段階に留め、閾値や重みの変更は行っていない。
